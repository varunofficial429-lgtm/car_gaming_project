🏎️ Car Racing Game

Project Description

Car Racing Game is a simple 2D game developed using Python 3 and Pygame. In this game, the player controls a car and moves left or right on a road to avoid incoming obstacle cars. The player earns points for every obstacle successfully passed. The game ends when the player's car collides with an obstacle.

Objective

The objective of this project is to develop a basic car racing game using Python programming concepts such as loops, conditional statements, keyboard input, collision detection, and game logic.

Features

- 400 × 600 game window
- Player car movement using arrow keys
- Road and road boundaries
- Enemy/obstacle cars
- Score tracking
- Collision detection
- Game Over screen
- Restart functionality using the R key
- 60 FPS game loop

Technologies Used

- Python 3
- Pygame

Installation

Install Python 3 and Pygame.

Install Pygame using:

pip install pygame

Or install all required dependencies using:

pip install -r requirements.txt

How to Run

Run the following command in the terminal:

python car_racing.py

Controls

Key| Action
LEFT Arrow| Move car left
RIGHT Arrow| Move car right
R| Restart game
X / Close Window| Exit game

Gameplay

The player must avoid obstacle cars coming from the top of the screen. Every obstacle successfully passed increases the score by one point. If the player's car collides with an obstacle, the game displays Game Over. The player can restart the game by pressing R.
